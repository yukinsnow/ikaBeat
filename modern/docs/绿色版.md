# 桌面绿色版

作者：**[Github@Yukinsnow](https://github.com/Yukinsnow)**。

## Windows x64

把整个绿色版 ZIP 解压到可写文件夹，双击 `ikaBeat.exe` 即可运行，不需要 ikaBeat 安装程序或管理员权限。

目录中的 `portable.flag` 使程序在启动时将 Tauri 应用目录重定向到 EXE 旁的 `data/`。WebView 的 localStorage、历史记录及缓存使用该目录。迁移时复制整个文件夹；重置时退出程序再删除 `data/`。原有安装版的历史不会自动迁移。不要删除标记文件或直接在压缩软件内启动 EXE。

轻量绿色包依赖系统已有的 Microsoft Edge WebView2 Runtime，不附带或自动安装运行时；因此它不是在缺少 WebView2 的 Windows 上也能直接运行的完全自包含包。分析引擎、网页界面和原图资源已嵌入程序，不需要 Node.js 或 Rust。[WebView2 分发说明](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution)。

## macOS

Universal `.app` 压缩包覆盖 Apple Silicon 和 Intel Mac。解压后打开 `ikaBeat.app`，无需安装向导。macOS 历史和缓存仍使用系统标准应用数据目录，不承诺所有数据随 `.app` 携带。此包未正式签名或公证。

## 构建和验收

[绿色版 GitHub Actions 构建](https://github.com/yukinsnow/ikaBeat/actions/runs/39366673811)，对应代码 revision：`d273aba20223eb123c17c91f62ebfb884886bb14`。

构建流程在 Windows 使用 `tauri build --no-bundle`，在 macOS 生成 Universal `.app` 并保留包内权限及符号链接。Windows ZIP 同时附带 `portable.flag`、使用说明和第三方许可。

两项云端构建均已成功。Windows 产物已检查为 x64 PE，导入表中没有额外的 VCRUNTIME / MSVCP 或 WebView2Loader DLL 依赖；系统 WebView2 Runtime 的要求仍然存在。macOS 包内可执行文件已检查为包含 ARM64 和 x86_64 的 Universal 二进制。ZIP 下载摘要已与 GitHub Artifacts 的 SHA256 digest 核对。

绿色版和之前的安装版独立提供。绿色模式不代表系统不会留下进程、最近访问或安全检测等操作系统记录。原生启动和文件导入导出仍应在目标设备验收。
