## 运行验收边界

本次没有在原生应用或手机真机内运行完整的导入 → 分析 → 导出路径。格式兼容、移动端文件选择与保存、低内存手机峰值内存仍需实机验收。浏览器测试不替代这些验收。

iOS 未签名 IPA 无法直接安装到普通 iPhone，需要开发者证书和相应 provisioning。Android APK 是可供测试的开发版本，尚不是用于商店发布的签名 Release / AAB。Windows 和 macOS 包没有正式签名 / 公证。

所有原版横幅、角色图片和应用图标均保留。变更已通过 PR #5 合并到 main，下载见 [v2.0.0 正式版 Release](https://github.com/yukinsnow/ikaBeat/releases/tag/v2.0.0)。
