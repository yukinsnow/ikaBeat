ikaBeat 2.0.0 Windows x64 绿色版
Github@Yukinsnow — https://github.com/Yukinsnow

1. 把整个 ZIP 解压到有写入权限的文件夹，例如 D:\Tools\ikaBeat。
2. 双击 ikaBeat.exe 运行。无需运行安装程序或管理员权限。
3. portable.flag 是绿色模式标记，请保留在 EXE 旁。
4. 历史记录、WebView 缓存等应用数据写入旁边的 data 文件夹。
5. 迁移时复制整个文件夹；清除记录时先退出应用，再删除 data 文件夹。

需要系统已有 Microsoft Edge WebView2 Runtime。
本包不附带 WebView2，也不会自动安装它。缺少该组件的电脑仍需要先准备运行时。
源代码及音频分析资源已嵌入程序，无需 Node.js、Rust 或联网下载分析引擎。

原先安装版的历史记录不会自动迁入绿色版。
请先解压再运行，不要直接在压缩软件里双击 EXE。
本版本未正式代码签名。系统可能显示发布者未验证。

开源信息：ikaBeat 代码 GPLv3，Essentia.js AGPLv3，详见附带许可及 THIRD_PARTY.md。
